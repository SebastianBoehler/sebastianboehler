|---|---:|---|
| Running job reserve | 0.5 h | Preserve the job unchanged. Charge any future simulator use to this reserve; measure actual use. If it needs more, reduce the new work before dispatch. |
| Alternative: feasible ≥3-component search | 2.0 h | Main coherent test of a different composition domain, including a small input/entry-point smoke and bounded repair. The coordinator sets call caps from measured cost. |
| Matched two-component control | 1.0 h | Same evaluator and comparable candidate-evaluation effort. Reuse existing results only if their provenance and budgets justify parity; otherwise run a matched control. |
| Confirmation and uncertainty | 0.5 h | Repeat top feasible candidates or a discriminating check if simulator noise and actual cost warrant it. Otherwise retain as unused reserve; do not spend it merely to fill the budget. |
| **Total ceiling** | **4.0 h** | Includes all future simulator use from the running job and all newly authorized tests. |

These are proposed caps, not observed resource consumption. The 2.0-hour alternative and 1.0-hour control are not inherently equal search budgets: the coordinator must set equal call or compute budgets for the actual comparison, using any remaining alternative time for separately labeled feasibility validation or broader exploration. If equal effort is impossible, report the comparison as budget-mismatched. Before starting, subtract the running job's verified remaining use and adjust caps without changing that job. If reliable per-call accounting or control parity is unavailable, limit the work to an implementation/feasibility check and avoid a performance conclusion.
